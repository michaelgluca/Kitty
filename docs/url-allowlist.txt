# Outbound URL allowlist
#
# Every URL the app can send a user to, with a fragment its page title must contain.
# Checked by scripts/check-urls.sh on every push and weekly on a schedule.
#
# Format:   <url> | <title fragment>
#
# Why a title fragment and not just "returns 200":
#   - emergencysms.org.uk still returns 200. It was taken over and its title is now
#     "Best Casinos Not on Gamstop" — while still being linked from UK police and
#     fire service pages.
#   - A wrong Apple support article ID also returns 200, on an unrelated article.
#   - chat.womensaid.org.uk "worked" only because the checker followed its redirect
#     to a different page. Women's Aid closed that chat on 31 July 2025.
# "Resolves" and "is still the right page" are different claims.
#
# Adding a URL here requires a citation to the issuing body's own page in the PR.
# URLs must be canonical: the checker fails on any redirect to a different address.
